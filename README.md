# Abdur Rauf: Personal Portfolio Website

All files are in ONE flat folder (no sub-folders), so they can be uploaded to GitHub with the "choose your files" button.

Files: index.html, style.css, main.js, config.js, hero-code.svg, favicon.svg, og-image.png, Abdur-Rauf-CV.pdf

## Run locally (VS Code)
Open this folder in VS Code, install the Live Server extension, right-click index.html and choose "Open with Live Server".

## What to edit
- Email, phone, LinkedIn, GitHub, CV file name, project status: config.js (explained in comments)
- Show your phone number: type it in `phone` and set `showPhone: true`
- Your CV: replace Abdur-Rauf-CV.pdf (same file name)
- Text and skill levels: index.html. Colors and fonts: top of style.css
